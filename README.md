# Gestionale_gunpla_FULL_STACK_PYTHON


## Dettaglio dei parametri principali:
* **`MYSQL_HOST`**: l'indirizzo IP o l'host del server MySQL (ad es. `127.0.0.1` per il server locale)[cite: 1].
* **`MYSQL_PORT`**: la porta usata dal servizio MySQL (di default `3306`)[cite: 1].
* **`MYSQL_USER`**: il nome dell'utente applicativo abilitato ad accedere al database[cite: 1].
* **`MYSQL_PASSWORD`**: la password dell'utente del database locale[cite: 1].
* **`MYSQL_DATABASE`**: il nome dello specifico database a cui l'applicazione deve connettersi[cite: 1].

Queste variabili vengono lette dall'applicazione Python (ad esempio utilizzando il pacchetto `python-dotenv`) per configurare la connessione al database in modo sicuro e centralizzato
